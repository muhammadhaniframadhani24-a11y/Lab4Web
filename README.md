## Deskripsi
Repository ini berisi latihan CSS Layout yang mencakup box element, CSS float dan clear, HTML5 semantic elements, serta pembuatan layout web sederhana. Halaman tambahan About dan Contact dibuat untuk memenuhi pertanyaan dan tugas pada modul.

## Daftar File
- `home.html` — halaman utama dengan header, navigasi, hero panel, konten, sidebar, widget, artikel, dan footer.
- `about.html` — halaman deskripsi dan portofolio.
- `contact.html` — halaman formulir kontak berisi nama, email, subjek, dan pesan.
- `box.html` — demonstrasi box element, float, dan clear.
- `style.css` — stylesheet untuk seluruh halaman.
- `screenshots/` — tempat menyimpan screenshot hasil praktikum.

## Langkah Praktikum
1. Membuat folder project dengan nama `Lab4Web`.
2. Membuat file `home.html` sebagai kerangka dokumen HTML.
3. Membuat `style.css` dan menghubungkannya ke dokumen HTML menggunakan tag `link`.
4. Menambahkan elemen box dan mengatur warna menggunakan CSS.
5. Menerapkan `float: left` pada tiga elemen dan mengamati posisi elemen.
6. Menerapkan `clear: left` pada Div 4 agar tampil di bawah elemen yang mengambang.
7. Membuat layout utama dengan header, nav, hero, main content, sidebar, dan footer.
8. Mengatur navigasi dan tampilan hero panel.
9. Mengatur main content dan sidebar.
10. Menambahkan widget pada sidebar.
11. Menambahkan tiga kartu konten dan artikel.
12. Membuat halaman `about.html` berisi deskripsi dan portofolio.
13. Membuat halaman `contact.html` berisi form nama, email, subjek, dan pesan.
14. Menguji semua halaman melalui browser dan memeriksa tampilan pada ukuran layar berbeda.
15. Mengambil screenshot hasil tiap bagian, lalu menyimpannya di folder `screenshots/`.
16. Melakukan commit dan push ke repository GitHub bernama `Lab4Web`.
17. Mengirim URL repository ke e-campus.

1. Buka folder ini di Visual Studio Code.
2. Buka `home.html` menggunakan Live Server, atau klik dua kali file `home.html` untuk membukanya di browser.
3. Gunakan navigasi untuk membuka halaman About, Contact, dan Box Element.
